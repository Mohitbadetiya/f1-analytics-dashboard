# F1 Analytics Dashboard

An end-to-end Formula 1 analytics project — from data cleaning to a deployed
interactive dashboard with custom driver-rating analytics and a machine
learning prediction module.

**Dataset:** [Formula 1 World Championship 1950–2025](https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020) (Kaggle)
